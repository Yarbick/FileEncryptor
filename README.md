# FileEncryptor

> **Индивидуальный проект** на тему *"Разработка программы для шифрования файлов."*

**Автор:** ученик 10 "В" класса **Ярбилов Ильяс**

---

### О проекте

**FyleEncryptor** является десктопным приложением для шифрования и расшифрования файлов. В основе лежат три оригинальных
алгоритма, построенных на базе олимпиадных алгоритмов.

---

### Базовые требования для сборки

Для компиляции проекта из исходного кода нужны элементы:

* **Компилятор:** *MinGW 11.0+ (w64)* с поддержкой стандарта *С++20*
* **Система сборки:** *CMake 4.2+*
* **Desktop-Фреймворк:** *Qt6* (модуль `Qt6::Widgets`)
